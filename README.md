# Welcome To MakeKoshary 3D! 

![Image] ("C:\Users\YAHIAPC\Desktop\MakeKoshary-3d\public\textures\Screenshot 2026-08-17 182604.png")

MakeKoshary 3D is a game about running a small food stall and making a delicous local dish **koshary** in a small Egyptian village inspired by home village.

### How to Play

The game mechanics are simple because you'll only ever use one key and that key the space key. In order to start pouring the ingredients you need to hold space and to stop pouring you let the space key go. The catch is that if you let go of the space key too early you risk underpouring, and if you hold it for too long you will overpour and lose points if you exceed the tolerance for mistakes. And I know what you're thinking, this is lowkey easy, and this is why I added progressive difficulty so that the more customers you serve your pouring speed becomes faster and the tolerance for mistakes becomes slower and the amount of ingredients increase, so try it and see how long you can last.

### Tools

This project uses basic HTML and CSS and a handy JS library called Three.js which allows me to add the cool 3d shapes for the ingredients. It also uses Rapier (a package for 3js) which adds physics, how cool! Finally, I used vite for project setup and to more easily run and build my project.

### Inspiration

I was inspired to make this project for my love of koshary because growing up I used to get koshary with my cousins when visiting my home village and that would usually be the highlight of my visit and now looking back at those memories they bring me so much comfort and warmth so i wanted to make this game that tries to capture some of these memories. I specifically picked THREE.JS for this project because I wanted to improve my threejs.
